# Pomodoro Timer

A simple single-page Pomodoro timer in plain HTML, CSS and JavaScript. No build step and no dependencies.

## Features
- Focus, short break and long break modes (long break every 4 sessions)
- Start / pause / reset / skip, with a progress bar
- Adjustable durations, saved in your browser
- Optional auto-start of the next block
- Beep when a block ends; time left shown in the tab title
- Keyboard: `Space` start/pause, `R` reset

## Run
Open `index.html` in any browser.
